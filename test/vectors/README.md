# Wrapper-level replay vectors

Generated by `tools/gen_tt_vectors.sh` (source: `rtl/bin/dump_tt_vectors.ml`), committed so TT CI needs no OCaml.
Replayed by `test/test.py` for both RTL (`make`) and gate-level (`make GATES=yes`) runs.

Line format, one per clock cycle, hex: `rst_n ui_in uio_in exp_uio_oe exp_uio_out exp_uo_out`.

Oracle: spec interpreter (`spec/src/interp.ml`) plus a hand model of the wrapper's reset synchroniser
(`Rst_sync` in the exporter). The synchroniser model is checked only by this replay. Negative control
(2026-10-16): bypassing the synchroniser in the wrapper fails random_1/2/3 and reset_then_reload.
uart_d4 and qed_d5_reload do not detect that mutant, because a power-on-only reset hides the 2-cycle release delay.

| scenario | cycles | content |
|---|---|---|
| uart_d4 | 1733 | load UART TX d=4 (64 words), run, 1-cycle RUN drop, run |
| qed_d5_reload | 2766 | UART d=3, halt, reload timed-QED twin d=5, run |
| reset_then_reload | 2869 | reset mid-run with RUN high (imem retained, restart at 0), halt, reload QED d=3, run |
| random_1..3 | ~2150 each | 64 random words, random RUN/WSTB/uio/ui_low with rare rst_n pulses, partial reload, again |

Every scenario loads all 64 words before the first RUN: instruction memory has no reset, so its power-up
contents (X in gate-level sim) differ from the spec's zero-initialised model.

## Core v1 (branch v1-tt)

`v1_*.vec` are generated by `rtl_v1/bin/dump_tt_vectors_v1.exe test/vectors` (Hardcaml cyclesim of
`pemu_core_v1m` with the all-15 ROM library and behavioural SRAMs, plus a model of the wrapper's reset
synchroniser). `test/test.py` replays only `v1_*`; the v0.1 vectors above are kept for history.

| scenario | cycles | content |
|---|---|---|
| v1_rom_uart | 12,817 | ID read; lane 0 UART TX d = 4 with ROM package 0 (no firing), start-bit mutant (fail 0x15), CLR_VERDICT |
| v1_loadable_l1 | 35,721 | lane 1 UART TX d = 4 on uio[1] with the package loaded into the store (units 6, 7) |
| v1_reset_mid | 9,133 | rst_n pulse while lane 0 runs; ID read, reload, restart |
